# HZ Spawn Control

Специализированный серверный мод для Minecraft 1.20.1, Forge 47.4.21+, Epic Hunt 1.4.2.
Содержит 76 атомарных профилей спавна из `мобы.txt`.

## Что делает

* собственный `hz_spawn_control:replace_spawn` удаляет все старые записи вида и добавляет одну итоговую;
* таблицы биомов, веса и группы находятся в `src/main/resources/data/.../biome_modifier/`;
* дополнительные поверхности разрешаются через `SpawnPlacementRegisterEvent` с `Operation.OR`;
* `config/hz_spawn_control/limits.json` создаётся автоматически при первом запуске;
* лимиты считаются отдельно для каждого вида и действуют только на NATURAL/CHUNK_GENERATION;
* яйца, команды, разведение и ведра напрямую не блокируются.

## Сборка

Java 17. Локально с установленным Gradle 8.8:

```bash
gradle build
```

JAR: `build/libs/hz-spawn-control-forge-1.20.1-1.0.0.jar`.
Также можно загрузить проект в GitHub и скачать JAR из Actions -> Artifacts.

## Переход со старой системы

1. Сделайте резервную копию мира.
2. Удалите InControl и CraftTweaker, если они больше нигде не нужны.
3. Удалите старые `spawn.json`, `potentialspawn.json`, spawn-скрипты KubeJS и старые datapack-модификаторы.
4. Оставьте Epic Hunt 1.4.2 и VanillaBackport 1.1.7.10.
5. Установите собранный JAR одновременно на сервер и клиент (в модпак).
6. Полностью перезапустите сервер.

## Диагностика

В логе ожидаются:

```text
Registered 10 additive spawn-placement rules
Loaded 76 local spawn-limit rules
```

## Настройка

После первого запуска редактируйте `config/hz_spawn_control/limits.json`.
`chance`: 0.0..1.0. `localLimit`: максимум вида в локальном параллелепипеде.
Изменение таблиц биомов требует правки JSON в проекте и пересборки либо внешнего datapack override.

## Важное

Первая версия намеренно не изменяет глобальный ванильный cap категории CREATURE через mixin.
Сначала проверяется корректность разнообразия и отсутствие перенаселения. Увеличение глобального cap
лучше добавлять отдельным этапом после игрового теста.
